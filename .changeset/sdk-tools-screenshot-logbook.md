Add `screenshot_logbook`, a built-in tool that keeps a captioned log of images already inside the project root, imported from the subpath `@theokit/sdk-tools/screenshot-logbook` (`createScreenshotLogbookTool`). Action `record` appends an entry (root-relative path, media type, size, caption, time) for a png, jpeg, gif or webp file; action `list` returns the latest entries and the total. The log is a JSON Lines file under the project root (`logbook/screenshots.jsonl` by default) that holds references, never image bytes, and is rewritten through a temp file and a rename. Recording the same image twice gives two entries. Captions default to at most 500 characters and a log to at most 1000 entries (`maxCaptionChars`, `maxEntries`). Records on one tool instance run one at a time; two processes or two instances writing one log are not serialised and can lose an entry. Paths outside the root or under a secret segment are refused, and every failure is a typed result (`invalid_input`, `path_traversal`, `caption_too_long`, `unsupported_image_type`, `image_not_found`, `empty_image`, `log_full`, `log_corrupt`, `write_failed`) that leaves the log unchanged.
