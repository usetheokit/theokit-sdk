`@theokit/sdk` now exports `parsePluginManifest`, `installWorkspacePlugin`, `trustWorkspacePlugin` and `untrustWorkspacePlugin` (with `PluginManifest`, `PluginManifestError` and `TrustRecordError`) to install a workspace plugin and trust its folder without editing the trust record by hand.
